# Open issues of the OpenJEVis repository

Status of the 93 issues that were still open in [OpenJEVis/JEVis](https://github.com/OpenJEVis/JEVis/issues) when this fork

- **fixed**: changed in this fork (see the commits that mention `OpenJEVis#<number>`).
- **already fixed** / **obsolete**: no change needed, the reason is given.
- **open – needs decision**: the fix is small, but it changes behaviour or the issue is a question.
- **open – larger feature**: more than about a day of work; the note says what it would take.
- **open – unclear**: the issue text is not enough to act on.
